# Supplier List Pagination – 2026-09-10

Updated the Supplier Management list UI only.

- Supplier records are displayed in pages instead of one long table.
- Page size options: 25, 50, 100 records.
- Default page size: 50 records.
- First / Previous / Next / Last navigation.
- Shows current range and total record count.
- Row numbering remains continuous across pages.
- Pagination resets to page 1 when search, status/group filters, sorting, or page size changes.
- Existing backend, API, database schema, supplier calculations, and CRUD actions were not changed.
