# خطوات حل مشكلة الاتصال من الهاتف

بما أنك قمت بتنفيذ أوامر `npm run build` و `npx cap sync android` و `npm run cap:patch-android` بنجاح، فإن إعدادات الأندرويد الآن صحيحة تماماً.

لكن لماذا تظهر المشكلة على الهاتف؟ هناك سببان رئيسيان:

### 1. يجب تصدير التطبيق (APK) من جديد
التعديلات التي قام بها سكربت الترقيع تمت على **ملفات الكود المصدري** على الكمبيوتر (AndroidManifest.xml).
لكي يعمل التطبيق على هاتفك، **يجب عليك فتح مشروع الأندرويد في Android Studio وعمل Build APK من جديد** وتثبيت التطبيق الجديد على هاتفك.
إذا لم تقم بتثبيت النسخة الجديدة، فسيظل هاتفك يستخدم النسخة القديمة التي ترفض اتصال `http://`.

### 2. جدار حماية الويندوز (Windows Firewall) يمنع الاتصال
بشكل افتراضي، يمنع ويندوز أي جهاز خارجي (مثل هاتفك) من الاتصال بالكمبيوتر كإجراء أمني.
لقد قمت بإنشاء ملف باسم `ALLOW_PORT_3000.bat` في مجلد المشروع لفتح المنفذ بسهولة.
- انقر بزر الماوس الأيمن على ملف `ALLOW_PORT_3000.bat`
- اختر **Run as administrator** (تشغيل كمسؤول).
- سيقوم هذا الملف بالسماح للهاتف بالاتصال بالسيرفر.

### 3. تأكد من أن السيرفر يعمل
تأكد أنك قمت بتشغيل `start.bat` أو `npm run start` وأن الشاشة السوداء (محث الأوامر) تعمل وتظهر رسالة أن السيرفر يعمل.
